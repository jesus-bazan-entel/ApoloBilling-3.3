Guia de Instalacion Automatizada

Instalacion en Una Linea

La forma mas rapida de instalar ApoloBilling es ejecutando un solo comando:

curl -sSL https://raw.githubusercontent.com/jesus-bazan-entel/ApoloBillingv3/main/install/apolobilling.sh | sudo bash -s install

Este comando descarga y ejecuta el script de instalacion automatizado que:

  • Detecta tu sistema operativo y recursos
  • Instala todas las dependencias
  • Configura las bases de datos
  • Compila los componentes Rust y React
  • Configura los servicios systemd
  • Genera credenciales seguras automaticamente

Instalacion Paso a Paso (Manual)

Si prefieres mas control sobre el proceso, puedes clonar el repositorio y ejecutar el script localmente:

1 Clonar el repositorio
git clone https://github.com/jesus-bazan-entel/ApoloBillingv3.git /opt/ApoloBilling cd /opt/ApoloBilling/install
2 Dar permisos de ejecucion
chmod +x apolobilling.sh
3 Ejecutar la instalacion
sudo ./apolobilling.sh install

Post-Instalacion

Acceso al Sistema:
  • URL: http://<IP_SERVIDOR>
  • Usuario: admin
  • Password: admin123 (cambiar inmediatamente)
Importante:
  • Cambiar la password del usuario admin
  • Las credenciales se guardan en /opt/ApoloBilling/credentials.txt
  • Eliminar ese archivo despues de guardar las credenciales
  • Configurar SSL con Let's Encrypt para produccion

Configurar SSL (Produccion)

# Instalar certbot apt install -y certbot python3-certbot-nginx # Obtener certificado certbot --nginx -d tu-dominio.com # Renovacion automatica systemctl enable certbot.timer
